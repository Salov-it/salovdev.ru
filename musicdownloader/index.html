ВОПРОСЫ И ОТВЕТЫ

Есть вопросы?

Коротко о приложении и его установке.

Для какой операционной системы приложение?

Текущая версия предназначена для Windows x64. Для точных требований смотри описание релиза на GitHub.

Нужно ли отдельно устанавливать .NET?

Релиз публикуется как self-contained сборка, поэтому .NET Runtime отдельно устанавливать не требуется.

Где скачать последнюю версию?

На странице последнего релиза GitHub.

Можно ли предложить новую функцию?

Да! Создай issue в репозитории проекта и опиши свою идею.
