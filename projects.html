Ёрш VPN
VPN-сервис
2026 — настоящее время
Собственный VPN-сервис, который я самостоятельно спроектировал, разработал и запустил.
Проект включает backend-платформу, Telegram-бота, веб-интерфейс, систему управления подписками, платежную инфраструктуру и управление VPN-серверами.
Основная функциональность:
• регистрация и управление пользователями;
• создание VPN-профилей через RemnaWave API;
• управление VPN-подписками;
• управление сроками действия подписок;
• отображение использованного трафика;
• Telegram-бот для взаимодействия с сервисом;
• веб-личный кабинет пользователя;
• интеграция платежной системы;
• webhook-обработка платежей;
• защита от повторной обработки платежей;
• система уведомлений;
• фоновые процессы и синхронизация данных;
• управление VPN-нодами;
• конфигурация Xray / VLESS;
• Docker-инфраструктура;
• reverse proxy через Nginx;
• HTTPS и SSL-сертификаты.
Архитектура:
Backend проекта написан на C# / .NET 8. Основная бизнес-логика, работа с пользователями, подписками, платежами и VPN-профилями реализована в собственном backend-приложении.
Для управления VPN-инфраструктурой используется RemnaWave API. Сервисы развёрнуты в Docker на нескольких VPS-серверах.
